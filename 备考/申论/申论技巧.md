# 1.申论技巧
## 1.基础规则
- 字数：仅能在作答字数范围内答题，超出无效。根据字数算出行数，行数/2（对策时/3）得出要点数，要点数如果与段落不匹配则代表需要融合段落要点，若与段落基本匹配则大概率一段一句概括
- 标点符号：占独立一格，除非在一行末尾，数字与标点符号可同一格
- 分段：字数限制较少时无需分段，较多时看情况分段，所有段落空两格
- 作答步骤：根据材料划分关键内容，根据关键内容粗略计算字数，最后答题
- 字数节约：减少形容词，保证主谓宾结构
- 材料应用范围：答题必定涉及所有材料，若在大作文前都没用上则作为大作文的参考材料
- 题目要求对应潜规则
  - 全面：有效词汇尽量多
  - 准确/符合实际/紧扣材料：材料关键词务必保留，甚至所在半句可照抄
  - 简明/简洁：前置提炼写短句
  - 内容具体：写大长句，主语+细节+例子
  - 总结/提炼：必须有前置提炼词
  - 分条：就近合并
  - 条理：就近合并、前置提炼


## 2.通用规则
- 紧扣材料：内容高度来源于材料，可适当简练
- 关键句来源
  - 首尾句
  - 书面表达
  - “实现了/确立了/建立了”等词语
- 多段整合：可将不同段落的内容融合成为一个概括点，但不要轻易打乱材料中的顺序
- 多人讲话：每个人的说话都可能对应一个观点或者多人整合为一个观点
- 例子分析：例子较短时无实际可参考内容，例子较长时可能包含信息点；可将事例作为分点作答时的补充说明
- 分点要求
  - 内容：尽量不要有交叉，并列举措要么全写，要么全不写
  - 顺序：一般按照材料顺序逐点概括
  - 准则：字数限制较少时需高度概括，但核心关键词必须保留
  - 上限：控制在5点以内，超出5点需要合并
- 大白话概括为对应种属：柏油路-交通道路，垃圾箱-环卫设施，整房子-居住环境改善
- 题目询问某人对问题是怎么解决的：前置无需概括问题，而是直接概括举措，通过详细描述举措是怎么解决什么问题
- 有问有答：总结要点后关联题目所问，判断要点是否准确回答了题目所问
- 关键词阅读法
  - 首尾位置
  - 最高级：最、根本、关键、第一、核心
  - 递进词：更、值得、进一步、特别
  - 转折词：但、然而、反之、尽管、仍然、还
  - 并列词：同时、另外、一方面
  - 结论词：这些、这种、种种、所以、因此、故此、总之
  - 引出观点：表示、强调、指出、资料显示
  - 特殊标点：冒号前面、破折号后面、引号、分号（顿号带‘等’，一般没用）
- 逻辑阅读法
  - 总分关系：首尾总结明显、小案例佐证、关键词重复----留总不留分
  - 并列关系：并列词、分号、话题转换，无明显从属关系----全留或全扔
- 踩点补救法
  - 主题词定位：阅读障碍时，跟踪题干主题词，有问有答，即是答案
  - 高频词圈定：阅读障碍时，在一段中找出现大于等于2次的有效词汇，反复提及，即是答案
  - 首尾相接：阅读障碍时，大长句子以逗号为单位，首尾半句相连接（有效部位），重点突出，即是答案



## 3.归纳概括题
- 适用题型：做法、现状、原因、功能、变化
- 谋篇布局：第一段首先总结概括多种做法为一类做法（可选），续几段分点阐明各个做法，概括的格式需要保持一定程度上的一致
- 政策发展过程：根据时间点划分不同阶段的政策变化，可将年份分类为不同大阶段
- 现状概况：不需要概括具体做法，只需抓住当前的情况即可


## 4.综合分析题
- 适用题型：理解、分析
- 区别归纳概括题：语言逻辑连贯，不硬性要求分点作答
- 回答层次：是什么 + 为什么 + 怎么办（根据材料而定，一般简略）
- 是什么：优先锁定题干提及语句其前后内容，整合成为对题干问题的阐释
- 怎么办：题干提及【出现什么问题】或者【什么很重要】，材料中出现对策需要写对策
- 分析变化题型：若有以前的情况，则对应以前的情况分析当前的变化；若无则单独讨论变化
- 出现不同主体：归纳成对不同主体的作用
- 单一段落不需要分出多个点


## 5.对策启示题
- 回答角度分类：概括对策、借鉴对策、提出对策
- 政府对企业的政策开头：鼓励、倡议、倡导、支持
- 政府对国家的政策开头：响应、贯彻落实
- 对策应用方式
  - 有原因：根据原因写对策
  - 无原因：根据问题写对策，问题一段内的周边细节（哪怕是例子）都有助于使反推对策丰满
  - 对策不具体：根据原因/问题拓展对策具体内容
  - 没有对策：发散思维写对策（启示题）
- 问题+对策形式
  - 题目要求“先指出问题”或“有针对性”：必须写问题
  - 问题与对策一一对应出现/要求分别谈问题并提出相应对策：回答时各分段分别概括问题+对策
  - 先提出所有问题再提出所有对策：回答时先概括所有问题，再根据概括问题顺序分点概括对策
- 对策推导：正面案例推导对策时需要归纳普适性
- 对策归纳：出现在材料中不同位置的内容可以出现在同一分类中，这取决于是否可以归为同一类措施
- 对策详细问题简：对策建议为内容主题，要有前置提炼词；概括问题言简意赅，小词罗列，尽量避免对原因和危害的描写
- 材料有对策原话：直接照抄
- 微观/宏观对策选择
  - 选择微观原因：字数多、身份基层
  - 选择宏观原因：字数少、身份太高（如省政府）
- 回答对策可以注重描述抓手而并非效果
- 题干分析一句话，该句话可分为前后半句，均为名词：首段做整句话的定义解释，前后半句可分作两段，每段阐释对应名词详细内涵。



## 6.应用文
### 1.结构
1. 标题：关于+主题词+的+文种（没有限定标题时）
2. 主送/称呼（取决于题干是否给出）
3. 内容
（1）背景、问题或成绩（高度概括）
（2）原因、危害或意义（简化分析）
（3）对策：绝大多数应用文以对策为主（细化具体）
（4）结尾：号召、展望、总结评价
4. 发文者/身份（取决于题干是否给出）+ 日期


### 2.分类

|文种|标题|称谓|落款|
|--|--|--|--|
|报告、通告、意见、通知|√|√|√|
|倡议书、公开信、宣传稿|√|√|√|
|发言稿、讲解稿|√|√||
|短评、新闻稿、提纲|√|||
|调查问卷、活动方案|√|||
|编者按、内容要点||||
|不要求格式|均可|||

### 3.技巧
- 适用题型：量词+文种
- 格式要求：尽量都要有标题，均可进行分点作答
- 内容要求：
  - 降低个人色彩
  - 未提及对象时称呼可默认“各位领导、同志们”
  - 注意自己的身份角度，材料中涉及其他身份角度的处理方式不要写入回答中
- 各类型技巧
  - 倡议书：提及正面案例+反面案例，反面案例概括现状，正面案例提炼启示；无需对问题产生的原因进行单独分析，主要提出问题，在对策提出中关联到原因的对应解决即可
  - 发言稿：开头需要简单介绍自己
  - 分享经验：除了做法外还应配套产生影响增强说服力
  - 会议简报：开头可简要概括会议的名称、人员等会议概要
  - 回复群众疑问的公开信：可以提及具体的人名，需要适当发散公务员面对群众质疑的解题思维：阐述具体原因+承认小错误+给出后续处理方法
  - 倡议书、工作汇报、考察报告、经验交流稿、通知/通告：对策占比非常高，绝对主体，对策应写出前置提炼
  - 提纲：也要按照完整的语言逻辑去阐述
- 题目要求【生动】【号召】【感染力】：结尾处做简单号召或祝福（结合主题词）
- 题目要求【得体】：开头做简单的介绍或说明


## 7.大作文
### 1.对策类结构
- 标题
- 开头：提出总论点（是什么）
- 过渡段：分析问题（为什么）
- 对策段：提出对策（怎么办）（1-3段）
- 结尾：总结+目的/总结+展望
- 结构：是什么+为什么+怎么办
- 展开方式
  - 讲道理：分论点+解释说明+重要性、必要性+怎么做
  - 举例子：分论点+解释说明+举例+小结（例证、对比、排比）


### 2.论证类结构
- 总论点
- 分论点
- 总结升华（结合我国实际情况目标）


### 3.技巧
- 确定涉及材料
  - 指定材料且无小题未用材料，用指定材料
  - 指定材料但有小题未用材料，用指定材料+未用材料
  - 未指定材料，用与题干相关的所有材料
  - 涉及领导人或者宏观政策出现
  - 存在隐式关联前面材料的情况
  - 用于大作文的材料内容不会用于其他材料题
- 内容提炼
  - 举例来源：既可选自材料中的例子，也可根据自己的生活积累举例论证
  - 举例差异性：从材料多例子中找到差异性去作分论点
  - 内容加工：将材料中的内容提炼为普适性的做法
  - 材料利用：未用材料提炼框架总分论点，已用材料填充论点内容
  - 关键把握：领导人讲话可以拿出来作为总分论点
- 结构要求
  - 论述要有逻辑关联
  - 论点内容不要重复
  - 认识论为主、方法论为辅
  - 必须要有结尾
  - 开篇短而有力，小于6行，说的是什么


## 8.做题积累
- 三农：农村、农民、农业
- 规范词：生活富裕、生态保护、产业发展
- 提升艺术设计能力、赋予产品更多价值、科技助力品牌建设、构建多元产品体系、创新用户触达渠道
- 涉及多人围绕一个事情进行讨论：围绕一个事情的多方面进行总结，若存在争议还可在每一方面分为正反双方进行概括
- 借鉴他人经验给出自身做法：无需处处提及自身做法与他人经验的联系，直接表述自身做法
- 发表相关改进建议：先总结出现的问题，再给出对策
- 存在长篇幅讨论与问题无关内容的情况
- 我的问题
  - 主次不分：主题是可行性建议、问题可简要概括，无需太过详细占字数
  - 拘泥格式：不必拘泥于说话的连贯性，无需过多赘余描述，可直接前置为问题
  - 段落舍弃草率：比如电商营收、积极行动、“互联网+咖啡”模式与即饮咖啡市场
  - 问题与对策不搭配：打造品牌与利用生产线、品牌、产业打造产业链无关系
- 对策的十大维度
  - 思想认识：宣传、教育、引导（电视广播、新媒体、进社区进学校）。
  - 制度机制：建立标准、完善法规、制定考核问责机制、建立长效机制。
  - 资金保障：加大财政投入、设立专项资金、引入社会资本、提供低息贷款。
  - 人才队伍：引进专业人才、加强业务培训、招募志愿者、配备专职人员。
  - 技术支撑：研发新技术、引进新设备、推广数字化管理、搭建信息平台。
  - 监督管理：加强日常巡查、建立红黑名单、畅通群众举报渠道。
  - 设施建设：完善硬件配套（垃圾桶、处理厂、道路等）。
  - 产业发展：培育龙头企业、延长产业链、发展深加工、促进产业升级。
  - 市场机制：发挥价格杠杆作用（涨价/跌价）、政府购买服务。
  - 社会共治：发挥行业协会作用、引导社会组织参与、推动居民自治。
